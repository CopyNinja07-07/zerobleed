How it works

The raw data stays in Zetaris. The broker plans from column names only, then sends each Nemotron worker a tiny card through Meterless Nightshift. If a worker needs a missing fact, it can only ask for a real column name, and the broker fetches that one cell. The Markovian engine carries a small scratchpad between steps instead of a growing conversation.
